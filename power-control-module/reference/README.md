# Reference material

Source documents and photos behind the JK design decisions, kept so the
figures in the docs can be traced. The manufacturers' documents remain their
owners' property and are here for reference only.

| File | What it is | Used in |
|---|---|---|

| [hobbs-halogen-swivel-mount-lamps.png](hobbs-halogen-swivel-mount-lamps.png) | Hobbs datasheet page, halogen swivel-mount lamps: 3×5 and 4×6 sizes, voltages, wattages, beam patterns, part numbers, dimensions | [13 — Rear floods](../docs/13-multi-module-system.md#rear-floods-hobbs-halogen); Q-23, D-34 |
| [rear-flood-front-IMG_4866.jpg](rear-flood-front-IMG_4866.jpg) | Owner's photo of a rear flood, lens side: fluted flood lens marked "SEALED BEAM" | Same |
| [rear-flood-back-IMG_4865.jpg](rear-flood-back-IMG_4865.jpg) | Owner's photo, housing side: "HOBBS" moulding, swivel bracket, cord printed with MSHA approval P-7K-123033, the gap at the cord entry | Same |

Photos are committed as JPEG copies made with
[`tools/heic_to_jpg.py`](../tools/heic_to_jpg.py), which drops all metadata:
the iPhone originals carry the GPS position where they were taken. `.heic`
files are ignored by git for the same reason.
